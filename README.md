# ULE4JIS-ALT

日本語配列 (JIS) と英語配列 (US) が混在する Windows 環境で、外付けキーボードを物理印字通りに打鍵できるようにするユーティリティです。

- **外付け US 化** (PC本体: JIS / OS: JIS設定): 外付けUSキーボードを印字通りに入力 💙 (トレイアイコン: **U**)
- **外付け JIS 化** (PC本体: US / OS: US設定): 外付けJISキーボードを印字通りに入力 ❤️ (トレイアイコン: **J**)

`ULE4JIS` の設計思想をリスペクトし、.NET 9 で再構築しました。

---

## 🚀 すぐに使う (ダウンロード)

1. **[最新バージョンのダウンロード (ULE4JIS-ALT.exe)](https://raw.githubusercontent.com/mana2p/ULE4JIS-ALT/master/publish/ULE4JIS-ALT.exe)**
2. ダウンロードした `ULE4JIS-ALT.exe` を実行するだけで、タスクバーの通知領域（トレイアイコン）に常駐します。
3. トレイアイコンを右クリックして、使用するモードを選択してください。

---

## 🧭 2つの動作モード

外付けキーボードの印字通りに記号が打てる**キー配列エミュレーションは、どちらのモードも設定不要で起動するだけで即座に動作**します。  
さらに、それぞれのキーボードの特性に合わせた**IMEアシスト機能**を搭載しています。

---

### 1. 外付け US 化モード 💙 (トレイ: U)
> **PC本体・OSが「JIS配列」で、外付け「USキーボード」を使う場合**

- **キー配列エミュレーション**: 外付けUSキーボードの印字通りに記号（`@`、`+`、`*`、`"`、`{` など）を入力。
- **左右 Alt 空打ち IME 切り替え (macOS風)**:  
  USキーボードには「変換」「無変換」キーがないため、左右 Alt キーで直感的に切り替えられます。
  - **左 Alt 単体**: 英語入力 (IME OFF) / 未確定時はカタカナ変換
  - **右 Alt 単体**: 日本語入力 (IME ON)
  > 💡 **Alt空打ち切り替えを利用する場合の推奨設定 (Microsoft IME)**  
  > Alt空打ち切り替えをより快適に動作させるため、WindowsのIME設定を推奨しています（キー配列エミュレーションのみ使う場合は不要です）：  
  > 1. タスクバー右下の IME アイコン（「あ」/「A」）を右クリック ➔ **「設定」**  
  > 2. **「キーとタッチのカスタマイズ」** ➔ **「キーの割り当て」** を **オン**  
  > 3. **無変換キー** を `IME-オフ`、**変換キー** を `IME-オン` に設定  

---

### 2. 外付け JIS 化モード ❤️ (トレイ: J)
> **PC本体・OSが「US配列」で、外付け「JISキーボード」を使う場合**

- **キー配列エミュレーション**: 外付けJISキーボードの印字通りに記号（`^`、`@`、`[`、`:` など）を入力。
- **JIS 特殊キー自動アシスト**:  
  US配列設定のOSでは無視されてしまうJISキーボード特有のキーを、事前設定不要で直感的に動くよう自動変換します：

| キー | 動作 |
| :--- | :--- |
| **半角 / 全角** | IME の ON / OFF をトグル切り替え |
| **変換** | **IME ON (日本語・かな入力)** |
| **無変換** | **IME OFF (英語・直接入力)** |
| **ひらがな** | **IME ON (日本語・かな入力)** |

※外付けJIS化モード選択時は、物理キーで操作できるため「左右Alt空打ちIME切り替え」は自動的にOFFになります。

---

## 🌟 共通の便利機能

- **キーボード自動識別 (内蔵 / 外付け切り替え)**:  
  入力された最初の1文字で「内蔵」か「外付け」かを瞬時に判別。ノートPC本体の内蔵キーボードを打鍵したときは自動的に変換をスルーします。
- **管理者権限アプリでも動作 (UIPI回避)**:  
  トレイメニューの **「Windows起動時に自動起動 (管理者権限)」** にチェックを入れるだけで、管理者権限アプリ上でもキー入力が制限されず動作します。
