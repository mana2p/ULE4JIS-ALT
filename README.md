# ULE4JIS-ALT

日本語配列 (JIS) と英語配列 (US) が混在する Windows 環境で、外付けキーボードも内蔵キーボードも物理印字通りに打鍵できるようにする常駐ユーティリティです。

- 💙 **内蔵: JIS / 外付け: US** (トレイアイコン: **U**)
- ❤️ **内蔵: US / 外付け: JIS** (トレイアイコン: **J**)

`ULE4JIS` の洗練された設計思想をリスペクトし、.NET 9 とモダンな RawInput デバイス識別で再構築しました。

---

## 📌 前提条件：Windows のキーボードレイアウト設定

本ツールは、**Windows のキーボードレイアウト設定を「JIS（日本語キーボード）」にした状態で使用します**（日本の Windows PC の標準設定のままで OK です）。

> 💡 **なぜ Windows 側を JIS 設定にするのか？**  
> Windows を JIS 設定にしておくことで、JIS キーボード側のすべてのキー（「半角/全角」「変換」「無変換（カタカナ変換/IMEオフ）」「ひらがな」）が **Windows IME ネイティブの機能として 100% 完全かつ安定して動作** します。

---

## 🚀 すぐに使う (ダウンロード)

1. **[最新バージョンのダウンロード (ULE4JIS-ALT.exe)](https://raw.githubusercontent.com/mana2p/ULE4JIS-ALT/master/publish/ULE4JIS-ALT.exe)**
2. ダウンロードした `ULE4JIS-ALT.exe` を実行するだけで、タスクバーの通知領域（トレイアイコン）に常駐します。
3. トレイアイコンを右クリックして、使用する環境に合ったモードを選択してください。

---

## 🧭 2つの動作モード

お使いのノートPC本体と外付けキーボードの組み合わせに合わせて選択してください。

| モード | PC本体 (内蔵) | 外付けキーボード | トレイ表示 |
| :--- | :--- | :--- | :--- |
| **内蔵: JIS / 外付け: US** (デフォルト) | **JIS 配列** | **US 配列** | 💙 **U** |
| **内蔵: US / 外付け: JIS** | **US 配列** | **JIS 配列** | ❤️ **J** |

### ⚡ RawInput による完全自動デバイス識別
キーボードから入力があった瞬間、それが**内蔵キーボードか外付けキーボードかをハードウェアレベルで瞬時に自動判別**します。

- **JIS 配列キーボードを叩いたとき**:  
  エミュレーションは一切行わず、**完全スルー（ネイティブ動作）** します。  
  「半角/全角」「変換」「無変換」「ひらがな」キーの動作や、無変換キーによるカタカナ変換など、JIS キーボードのすべての機能が本来の快適さのまま動作します。

- **US 配列キーボードを叩いたとき**:  
  **US on JIS 記号エミュレーション** と **左右 Alt 空打ち IME 切り替え** を自動適用します。  
  印字通りに記号（`@`、`+`、`*`、`"`、`{` など）が入力でき、左右 Alt キーで直感的に IME を操作できます。

---

## ⌨️ 左右 Alt 空打ち IME 切り替え (US キーボード打鍵時)

US 配列キーボードには「変換」「無変換」キーがないため、スペースキー両隣の **Alt キー単体空打ち** でスマートに IME を切り替えられます（macOS 風）。

- **左 Alt 単体空打ち**: 英語入力 (IME OFF) / 文字入力中はカタカナ変換
- **右 Alt 単体空打ち**: 日本語入力 (IME ON)
- **Alt + 他のキー (Alt+Tab, Alt+F4 など)**: 通常の Alt ショートカットとしてそのまま通過

> 💡 **Alt 空打ち切り替えを利用する場合の推奨設定 (Microsoft IME)**  
> 1. タスクバー右下の IME アイコン（「あ」/「A」）を右クリック ➔ **「設定」**  
> 2. **「キーとタッチのカスタマイズ」** ➔ **「キーの割り当て」** を **オン**  
> 3. **無変換キー** を `IME-オフ`、**変換キー** を `IME-オン` に設定  
> （※この設定により、左 Alt 空打ちで「文字入力中はカタカナ変換、未入力時は IME-オフ」という理想の挙動になります）

## 🌟 その他の便利機能

- **管理者権限アプリでも動作 (UIPI 回避)**:  
  トレイメニューの **「Windows起動時に自動起動 (管理者権限)」** にチェックを入れるだけで、タスクスケジューラ経由で管理者権限で起動し、VS Code やコマンドプロンプト等の管理者ウィンドウ上でも確実に動作します。
- **軽量・高速・常駐負荷ゼロ**:  
  低レベルキーボードフックと Win32 RawInput によるイベント駆動設計のため、CPU・メモリ消費はほぼゼロです。
