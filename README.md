# ULE4JIS-ALT

日本語配列 (JIS) と英語配列 (US) が混在する Windows 環境で、外付けキーボードを物理印字通りに打鍵できるようにする Windows 用ユーティリティです。  
- **外付け US 化** (PC本体: JIS / OS: JIS設定): 外付けUSキーボードを印字通りに入力 💙 (トレイアイコン: **U**)
- **外付け JIS 化** (PC本体: US / OS: US設定): 外付けJISキーボードを印字通りに入力 ❤️ (トレイアイコン: **J**)  
`ULE4JIS` の設計思想をリスペクトし、.NET 9 で再構築しました。

---

## 🌟 主な特徴

1. **双方向キーボード配列エミュレーション (外付けUS化 / 外付けJIS化)**
   - **外付けUS化**: OS側のキーボード設定が「JIS配列」のままでも、外付けUSキーボードの印字通りに記号入力を行えるよう変換。
   - **外付けJIS化**: OS側のキーボード設定が「US配列」のままでも、外付けJISキーボードの印字通りに記号入力を行えるよう変換。

2. **キーボードデバイス自動識別 (内蔵 / 外付け自動切り替え)**
   - 入力された最初の1文字目で「ノートPC本体の内蔵キーボード」か「外付けキーボード」かを瞬時に取得。
   - 外付けキーボードを打鍵すると選択したエミュレーションが自動適用され、ノートPC本体の内蔵キーボードを打鍵すると一切変換せずそのままスルーされます。

3. **左右 Alt 空打ちによるスマート IME 切り替え (macOS風)**
   - **左 Alt の空打ち**: 無変換キー (`VK_NONCONVERT`) を送信し、英語入力 (IME OFF) に切り替え。変換中ならカタカナ変換。
   - **右 Alt の空打ち**: 直接 IME ON 信号を送信し、日本語入力に切り替え。
   - `Alt + Tab` や `Alt + F4` などのショートカット操作時は通常の Alt として動作するため邪魔になりません。

4. **管理者権限アプリでも無効化されない自動起動 (UIPI回避)**
   - 管理者権限で起動したアプリケーションでキー入力が効かなくなる問題（Windows の UIPI 仕様）を回避。
   - トレイメニューから **「Windows起動時に自動起動 (管理者権限)」** を選択するだけで、タスクスケジューラの最上位特権タスクを自動作成・管理します。

## ⚙️ 事前設定 (Microsoft IME)

左右 Alt 空打ちによる IME 切り替え（macOS風）を正しく動作させるには、Windows の IME 設定でキーの割り当てを変更してください。

1. タスクバー右下の IME アイコン（「あ」/「A」）を右クリック ➔ **「設定」** を選択
2. **「キーとタッチのカスタマイズ」** をクリック
3. **「キーの割り当て」** を **オン** に変更
4. 以下のようにキーを設定：
   - **無変換キー**: `IME-オフ`
   - **変換キー**: `IME-オン`

> 💡 **なぜこの設定が必要なの？（設計のこだわり）**  
> - **左 Alt（無変換）**: 文字入力の未確定時に押すと **「カタカナ変換」** を行い、未入力の通常時に押すと **「IME オフ (英語入力)」** に切り替わります。直接強制的にIMEをOFFにするのではなく、Windows IMEの「未確定時のカタカナ変換」を活かすために無変換キー (`VK_NONCONVERT`) を送信する設計を採用しています。
> - **右 Alt（変換）**: どのような環境やアプリからでも一発で確実に日本語入力モードへ切り替えられるよう、OSのIME制御信号を直接送信しています。
> - **外付けJIS化モード時の「半角/全角」キー**: US配列設定のOS上では「半角/全角」キーが `` ` ``（バッククォート）として誤認されるため、本アプリが自動検知してIMEのON/OFF切り替えに変換します。

## 🚀 使い方 / ダウンロード

1. **[最新バージョンのダウンロード (ULE4JIS-ALT.exe)](https://raw.githubusercontent.com/mana2p/ULE4JIS-ALT/master/publish/ULE4JIS-ALT.exe)**
2. ダウンロードした `ULE4JIS-ALT.exe` を実行するだけで、タスクバーの通知領域（トレイアイコン）に常駐します。
3. トレイアイコンを右クリックすることで、各機能の ON / OFF 切り替えや自動識別、Windows 起動時の自動起動を設定できます。
